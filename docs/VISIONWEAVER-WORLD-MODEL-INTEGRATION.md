# The Arc — VisionWeaver World Model Integration

**Date:** 2026-10-03

The Arc's large-scale artificial worlds, ship interiors, exterior environments, vehicles, and moving systems should use VisionWeaver's persistent world-state model.

Relevant continuity domains include:
- 3D/spatial geometry
- fixed and moving assets
- environmental and atmospheric conditions
- light sources
- sound fields
- local air/fluid displacement
- character perception/reaction
- camera continuity
- temporal state
- causal event propagation

The Arc remains responsible for franchise canon. VisionWeaver provides the production-world simulation and continuity layer.
