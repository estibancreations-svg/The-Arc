## Stage 2 — quantified reality build

The controlling chain is:

`SOURCE → PROCESS → STOCK → COMPONENT → SUBSYSTEM → ASSEMBLY → ZONE → OPERATION → MAINTENANCE → RECOVERY`

Every animal, mineral, plant, microbe, material, structural member, machine, water class, habitat function and vehicle must eventually resolve to quantity, dimensions, mass/volume, composition, dependencies, utility flows, manufacturing/propagation route, maintenance, replacement and recovery.

The goal is a buildable **Bill of Systems + Bill of Materials + Ecology Dependency Graph + Construction Sequence**, not just a visual catalog.
